MCC CHARACTER — IPHONE VERSION

The complete website is in this folder. Keep all files and the assets folder together.

TO VIEW ON YOUR COMPUTER
Open this folder in VS Code and use Live Server on index.html.

TO PUT IT ON YOUR IPHONE HOME SCREEN
1. Publish the contents of this folder to an HTTPS website such as GitHub Pages.
2. Open the website address in Safari on your iPhone.
3. Tap Share (square with upward arrow), then Add to Home Screen, then Add.

An address beginning 127.0.0.1 works only on your own computer, not on your iPhone.
Once the site has loaded on the iPhone, the Home Screen version can also work offline.

If you already have a repository, upload the CONTENTS of this folder to its publishing root, keeping assets as a folder. GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root). It may take a few minutes for the link to appear.
